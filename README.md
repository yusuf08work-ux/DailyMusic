# DailyMusic

An Android music-player preview based on [Metrolist](https://github.com/MetrolistGroup/Metrolist).

## Download

[**Download DailyMusic 0.3.0 APK — approximately 24 MB**](https://github.com/yusuf08work-ux/DailyMusic/releases/download/v0.3.0-preview/DailyMusic-preview.apk)

Android 8.0 or newer is required. Install over your existing DailyMusic preview without uninstalling. The package identity and signing certificate are retained.

DailyMusic has a black-and-white interface with Home and Archive. Home includes search, swipeable Quick Picks and a compact genre wheel opening live music searches. This update fixes returning Home from search and adds a static waveform seek bar and wider cropped cover artwork in the expanded player. History remains available.

All 246 automated tests passed. Live genre results, real-device playback, artwork and scrubbing still need phone testing; this remains an early preview.
