# DailyMusic

An Android music-player preview based on [Metrolist](https://github.com/MetrolistGroup/Metrolist).

## Download

[**Download DailyMusic 0.2.0 APK — approximately 24 MB**](https://github.com/yusuf08work-ux/DailyMusic/releases/download/v0.2.0-preview/DailyMusic-preview.apk)

Android 8.0 or newer is required. Install over the first DailyMusic preview; do not uninstall first. The package identity and signing certificate are retained.

This preview introduces a black-and-white interface with two tabs: Home, with search and swipeable Quick Picks, and Archive, with rows for liked, downloaded, and most-played songs. History stays available. Login no longer forcibly restarts the app.

All 243 automated tests passed. Real-device scrolling and Google authentication still need phone testing; this remains an early preview, not a finished or fully audited app.
