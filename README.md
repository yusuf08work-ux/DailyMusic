# DailyMusic

An early Android music-player preview based on [Metrolist](https://github.com/MetrolistGroup/Metrolist).

## Download

Open [Releases](https://github.com/yusuf08work-ux/DailyMusic/releases) and download **DailyMusic-preview.apk** from the preview release's Assets section. Android 8.0 or newer is required.

This is a development build for testing. It uses distinct branding, smaller cache defaults, and disables AI translation. Playback reliability and account behavior still need physical-device testing; this is not a finished or fully audited app.

The exact source archive and SHA-256 checksum are provided alongside the APK. The source retains its upstream GPL-3.0 license, contributor credits, and notices. DailyMusic is independent of Google, YouTube, Morphe, and Metrolist's maintainers.
